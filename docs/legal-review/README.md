先阅读[联网核查结果与待确认事项-2026-11-03.md](联网核查结果与待确认事项-2026-11-03.md)。普通法规、条件和时限先由开发组查证处理，只在该文件第7节保留少量具体案件、真实受理样式和机构实际采信问题。

## 本次变更

- 用户要求删除的完整审核表、首轮审核表两份Excel已删除，更新后的ZIP也不再含这两份文件。
- 官方在线核查覆盖当前公共内容快照的18条知识、5条规则、12参数和6类最新模板及异议函；说明了需要更正的内容、来源与尚未实施的修改。
- 原始53份资料仍是候选资料，不代表全国各地都已逐份核实有效。48份提取文本保留，5份旧DOC仍待适当转换提取。
- 本轮未写回业务数据库、未发布规则版本、未部署服务器。数据中的旧reviewed不代表法学院签字认可。
