## 2. 已查清的核心结论

### 2.1 发改委第58号令已经废止

国家发改委第36号《信用修复管理办法》自2026年4月1日起施行，第三十条明确同时废止第58号令。旧项目文档将第58号令标注为“现行”，应更正。[发布页 S12](https://www.ndrc.gov.cn/xxgk/zcfb/fzggwl/202511/t20251126_1401911.html)、[官方全文PDF S13](https://www.ndrc.gov.cn/xxgk/zcfb/fzggwl/202511/P020251126424276238205.pdf)。

第36号令第五条区分信用平台与行业信用系统的适用范围，第十一条要求已有行业分类标准的按行业标准执行。因此不能把其轻微信息规则直接覆盖市场监管第107号令，更不能让税务、海关、法院共同使用一套月数和材料。

### 2.2 市场监管业务必须区分“申请修复”和“到期停止公示”

以下结论依据[第107号令全文 S02](https://www.gov.cn/zhengce/202512/content_7050596.htm)：

| 情形 | 办理口径 | 平台应如何展示 |
|---|---|---|
| 仅受警告 | 第七条：不予公示 | 不生成“三个月后可申请”的结论 |
| 仅受通报批评，或仅受较低数额罚款 | 第七条：公示满三个月由机关停止公示 | 显示预计停止公示节点；无需企业申请 |
| 较低数额罚款的构成 | 必须同时符合从轻/减轻裁量、经营主体五万元以下或责任人员五千元以下；还须核实是否仅处罚款 | 金额小不能单独得出轻微结论 |
| 一般行政处罚信息 | 第九、十一条：满三个月并符合条件可申请；满一年机关停止公示 | 分开显示最早申请节点、最长公示节点、实际官方结果 |
| 第八条第一项重点领域的严重信息 | 满一年且符合条件可申请，三年停止公示 | 必须核实领域和处罚类型，不能只看企业所属行业 |
| 限制经营、停产停业、限制从业 | 第八条第二项：还须限制期限届满 | 缺少限制期限信息时不自动判定可申请 |
| 降低资质等级、吊销许可证件/营业执照、责令关闭 | 第八条第三项：三年停止公示，未规定提前修复申请路径 | 不套用“严重=一年可申请”；不妨碍错误信息更正等其他救济 |
| 经营异常名录 | 第十二条：针对列入原因完成相应改正后可申请移出，无统一最低等待期 | 按实际列入原因匹配，不能要求五种改正全部完成 |
| 严重违法失信名单 | 第十三条：满一年可按条件申请，三年移出；法定管理措施未届满不得提前移出 | 与“严重行政处罚信息”分开建规则 |
| 抽查检查结果负面信息 | 第十条：分无处罚/轻微处罚与其他关联情形处理 | 暂无对应实现时提示不支持自动判断，不能借用普通处罚规则 |

经营异常可以“无等待期”，不等于所有情况“立即办结”。第十六条一般为受理后两个工作日；因住所无法联系列入的，决定期限从**核实之日**起算。

### 2.3 材料和办理时限已经有明确条文

第107号令第十四至十七条规定：申请书、主体资格文件、守信承诺书、履行义务/纠正违法/整改等相关材料；政务共享可取得的材料不得重复要求。材料齐全的，两工作日内受理；缺材料的，两工作日内一次告知补正。

经营异常移出适用上述两个工作日及住所核实例外。行政处罚、抽查检查结果负面信息、严重违法失信名单申请，自受理起七个工作日内决定。第十六条另规定情况复杂、不能在规定期限内决定的，经批准可延长十个工作日，不应将此例外误读成只适用于七日流程。准予修复后，三工作日内完成相应数据处理。**补正、受理、决定、数据处理是不同阶段，不能合并成一个“七天”。** [S02](https://www.gov.cn/zhengce/202512/content_7050596.htm)

授权委托书在确有委托时使用；整改计划不能代替已经完成整改的证明。平台自设的目录、计划、说明，不应全部标成每种事项的法定必交材料。

### 2.4 第三方更新有依据，但不存在全国通用“三日答复异议函”

- 第107号令第二十六条：提供经营主体信息查询服务的第三方机构，应根据国家企业信用信息公示系统信息即时更新；损害合法权益的依法承担责任。[S02](https://www.gov.cn/zhengce/202512/content_7050596.htm)
- 第36号令第二十四条：从“信用中国”获取信息的第三方机构应同步更新；信息不一致的以“信用中国”为准，并有暂停共享、约谈等处理机制。第十八条另规定信用中国异议申诉的转送、核查期限，不能搬作所有商业平台的答复期限。[S13](https://www.ndrc.gov.cn/xxgk/zcfb/fzggwl/202511/P020251126424276238205.pdf)
- 湖南条例第三十二条确有**本单位范围三工作日、需其他单位协助五工作日**的异议处理规则，且第三十三、三十四条还有其他三工作日规定。但需要匹配地域、处理主体和流程，不是任意平台收到任意函件后一律三天。[湖南官方转载 S19](https://www.yueyang.gov.cn/web/2570/2580/2729/2730/content_1981214.html)、[湘潭官方转载 S20](https://gxj.xiangtan.gov.cn/12950/12954/content_1030407.html)

所以`objection_sla_days=3`若只是平台自己的提醒策略，可以保留并明确标为自设提醒；不能作为普遍法定期限。现有异议函代码已写“处理期限以适用规则和平台受理答复为准”，这一点无需改成强制三日。

### 2.5 湖南的“即申即享”已经查到，不必再让用户找普通政策

湖南省市场监管局《推动实施经营主体信用修复“即申即享”工作机制的通知》，湘市监信〔2026〕39号，签署日期2026-07-24，官方登记号HNPR-2026-26005。范围为湖南登记、湖南公示系统中相应经营异常信息，符合条件时由官方系统自动比对、修复。[省政府登记页 S29](http://www.hunan.gov.cn/hnszf/xxgk/wjk/szbm/szfzsjg_19847/scjdglj/gfxwj_19835/202609/t20260909_34059869.html)、[省市场监管局全文 S30](http://amr.hunan.gov.cn/amr/zwx/xxgkmlx/tzggx/202609/t20260922_34070319.html)

例如年报异常需在列入后一年内补报公示，且近三年未因同一原因列入；住所异常完成变更登记的，也有近三年条件。不要把这些“即申即享”额外条件反向变成全国普通经营异常移出申请的限制。私营SaaS更不能宣称自己调用了官方自动修复接口。

省政府登记页显示信息时效期2031-08-17，全文写印发日起施行、有效期五年，两者元数据并不完全一致。本轮仅据此支持当前场景，不自动计算其远期失效日。

### 4.3 对照代码能直接定位的问题

以下为静态阅读，不是已经执行修复或通过回归测试：

1. `src/services/rules.js`的`evaluate()`虽返回`autoStopOnly`，`eligible`计算未排除该分支，仍套通用条件。要将无需申请与可申请结论分开。
2. 同文件经营异常缺义务完成日时提示“尚未取得移出决定”，容易把申请后的结果当成申请前提；应允许以补报公示、变更、重新联系等对应证据验证。
3. `levelCheck()`对轻微的“ok”结论尚未完整核实是否仅处罚款；非从轻减轻不必然就是一般，严重处罚还涉及领域、种类。缺关键事实时不得强推等级。
4. `applyFrom()`使用`listed_date`，注释却写决定作出日；不要仅改注释。第36号令第七条有其适用范围内起算规则，107号令没有在相同位置直接规定所有具体公示起点。应保存决定日期、实际公示日期、告知书起算依据并处理跨版本，不能引用已废止58号令直接外推。
5. `src/services/docs.js`的`build()`按处罚/经营异常加载全部最新模板，没有按规则材料列表筛选。应区分法定材料、条件性材料、辅助说明；主体资格文件作为外部证据，不能靠生成文字补齐。
6. `src/services/checks.js`当前异议函是待提交草稿，含人工核录来源，期限从适用规则/受理答复，不存在已自动送达的事实。法源增强应补引用，不得把模拟观察写成官方联网验证。

## 5. 六类最新文书和异议函

本轮检查的是各`doc_key`最大版本，均为v2；旧v1仅保留历史，不能因历史草稿引用过时就称当前生成版本仍如此。

| 文书 | 已能确定的处理 |
|---|---|
| 申请书 apply | 可作为辅助草稿；按事项匹配官方表格字段，不在事实缺失时预写“全部符合条件”；到期自动停公示路径不强制生成 |
| 承诺书 promise | 企业据实确认签章；以实际受理方公开格式核对具体承诺项目，不把平台占位文字当成已作承诺 |
| 整改说明 rectify | 写实际成因、措施、结果并关联凭证；不能由“已登记移出日期”证明已官方修复 |
| 授权委托书 auth | 仅委托办理时使用；填写范围、权限和期限；受托人证件信息不进入公开二维码页 |
| 材料目录 list | 按实际有效附件列名称、类别和日期；平台摘要只辅助核对，不代替原件核实 |
| 整改计划 plan | 可作辅助管理材料，不是所有申请必交，更不能以未来计划代替已消除危害后果的事实 |

已找到[东莞官方表格页面 S17](https://dgamr.dg.gov.cn/ywgz/xyjg/zlxz/content/post_4480321.html)及附件，页面日期2025-12-25。第107号令第二十九条规定统一格式范本，但仅凭这句话不能反推出所有自拟辅助说明都被禁止，也不能证明当前六类模板已获全国受理。

## 6. 二维码、银行采信与信息保护

107号令第十九条的电子文书与纸质同等效力，指市场监管部门送达的决定电子文书，不是私营平台生成的二维码记录自动取得同等身份。二维码及哈希能辅助核对平台记录的一致性，不能自己证明原始材料真实或官方已修复。官方结果应展示出具机关、文号、日期、来源与观察时间；第三方状态作为另一个独立状态展示。[S02](https://www.gov.cn/zhengce/202512/content_7050596.htm)

没有在本轮来源中查到“银行或招标单位依法必须接受本平台数字凭证”的依据。应写“辅助展示、供对方独立核查”，是否接受由具体机构及项目要求确定，不写“扫码即授信”“扫码必然通过资质审核”。

信息保护的普通法律依据也可自行查询，不必整包交给法学院寻找：[个人信息保护法 S33](http://www.npc.gov.cn/npc/c2/c30834/202108/t20210820_313088.html)第六、十三、十七、二十五、二十八至二十九条等涉及最小必要、处理依据、告知、公开和敏感信息；[网络数据安全管理条例 S32](https://www.gov.cn/zhengce/content/202409/content_6977766.htm)第三章规定个人信息保护。企业授权不当然替代员工、受托人等自然人信息所需的处理依据。二维码公开页应按用途脱敏，附件下载与机构查询须有相应权限；本轮只提出要求，未完成生产系统隐私合规验收。

## 7. 真正留给人工的少量问题

普通条文、金额、月数、材料类别和时限不用再逐条发给你。优先只确认下面三类：

| 问题 | 已完成的查询 | 人工只需补充什么 |
|---|---|---|
| 具体案件的时间与重复受罚口径 | 已查新36号令、107号令及湖南通知；公开一般条文不足以确定“同一类”的所有边界及每个历史案件的跨期/公示起点 | 由法学院结合1个脱敏样例审阅，必要时向实际受理机关确认；明确起算依据和重复行为范围。不要重新审全部表结构 |
| 湖南具体受理事项的最终材料样式 | 已找到四类材料法源、公开申请表和湖南即申即享通知；尚未登录企业电子营业执照办理界面 | 如需验证真实申报，只提供实际受理窗口/企业登录页下载的空白申请书、承诺书及补正要求即可；无需企业账号密码。当地可用格式不能由其他地区附件保证 |
| 银行/招标单位的实际采用要求 | 未发现强制接受私营平台二维码的规定；官方电子决定的效力已有条文 | 若准备对外宣称机构合作或采信，需合作方自己的书面要求或样例；没有合作方时使用辅助核验表述，不耽误平台演示 |

企业是否实际缴清、是否完成整改、材料真假、官方状态是否真的更新，必须有该企业自己的证据或可核查记录，不能通过一般法律检索替代。这些是业务事实，不另列成让法学院通读53份条例的任务。

## 8. 可追溯材料与后续执行

- `online/sources.json`：请求日期、来源URL、响应状态、实际保存文件及SHA-256；访问失败不算核实成功。搜索结果只用于找入口，结论取已读取的官方全文或明确标明的官方转载。
- `online/source-*.txt`及HTML/PDF：网页正文和原始响应留档。S09、S10为旧知识引用的媒体材料，本轮不以其作为定罪或法定期限的独立依据。
- `data/review-snapshot.json`：只读快照，对应表名、ID、版本；`data/数据库结构快照.sql`仅作技术对应，不要求法学院逐字段审核。
- `data/online-review-validation.json`：文件、条目数量、删除状态、来源完整性及更新后的压缩包验证。

建议接下来的开发顺序：先修申请/自动停止分支、严重子类型和经营异常条件，再更新18条知识及参数说明，按办理路径匹配文书，最后用脱敏例子验证普通申请、无需申请、限制未届满、经营异常已补报、官方已修复但第三方未更新五条流程。实施时新增版本保留历史，不把这次“来源已查到”自动标成法学院“已审核通过”。

本轮未连接或修改公网服务器，未写业务数据库，未变动应用运行逻辑；以上开发修正仍是待实施清单。
