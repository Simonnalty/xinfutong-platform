# 信用修复法规核验与合规知识库

**编制日期**：2026-10-31
**用途**：为平台「13 个规则字段」提供现行有效法规依据；为「合规知识库」提供可直接入库的内容条目
**核验方式**：全部条文取自政府官方网站（中国政府网、发改委、市场监管总局、国家税务总局、海关总署、最高人民法院、信用中国地方站），文号与施行日期逐条核对

---

## 一、三条必须先看的结论

### 结论 1：法规已经换代，平台现有规则是旧口径

2025 年有两部关键文件落地，平台代码里的参数没有跟上：

| 文件 | 时间 | 对平台的影响 |
|---|---|---|
| 国办发〔2025〕22 号《关于进一步完善信用修复制度的实施方案》 | 2025-06-22 印发 | 确立全国统一的三类分类标准、统一受理渠道、统一时限 |
| 市场监管总局令第 107 号《市场监督管理信用修复管理办法》 | 2025-11-21 公布，**2025-12-25 施行** | 替代 2021 年旧办法，公示期、材料、时限全部改写 |

今天是 2026-10-31，107 号令已施行满 10 个月。平台若仍按旧办法判定，给出的「可申请日」会晚于法定时点，等于让企业白等。

### 结论 2：现有代码有 8 处与现行法规不一致

详见第五节。其中两处会直接导致错误结论：

- **经营异常名录类**：平台要求「已移出」才算满足条件，法规是「已补报即可申请移出」，没有等待期
- **「近 12 个月无新增同类」**：法规原文没有 12 个月的时间窗口，这是平台自造的口径

### 结论 3：合规知识库目前是空的

`knowledge_entries` 表 0 条记录，前端「合规知识库」页面打开是空白。第七节给出 19 条可入库内容，每条都带来源链接和生效日期，可直接录入。

## 三、13 个字段逐条对照现行法规

以下每个字段给出：法规怎么规定（含条号）、平台上应该填什么、代码落点在哪、现有实现有什么问题。

### 字段 1｜情形名称

| 项 | 内容 |
|---|---|
| 法规口径 | 必须用官方全称。107 号令第二条把违法失信信息分成四类：行政处罚、抽查检查结果负面信息、列入经营异常名录、列入严重违法失信名单 |
| 应填 | 四类之一的全称，如「市场监督管理领域一般违法失信信息（行政处罚）」 |
| 系统落点 | `cases.event`、`rule_versions.rule_key` |
| 现有问题 | 平台只有「行政处罚／经营异常名录」两种 `case_type`，缺「抽查检查结果负面信息」这一类。107 号令把它单列为可修复对象（第十条），是本次修订新增的修复渠道 |

**新增说明**：抽查检查结果负面信息（双随机检查、食品抽检、产品质量抽查不合格等）此前不在修复范围，107 号令第十条明确：未作行政处罚或仅作轻微处罚的，公示满 3 个月由登记地监管部门停止公示，**无需申请**。

### 字段 4｜失信等级

这是差异最大的一项。

| 项 | 内容 |
|---|---|
| 法规口径 | **只有三类**：轻微、一般、严重（国办发〔2025〕22 号第二项；107 号令第六条） |
| 轻微 | 仅警告／仅通报批评／仅较低数额罚款（经营主体 5 万元以下、责任人 5000 元以下）（第七条） |
| 一般 | 除轻微、严重外的其他行政处罚（第九条） |
| 严重 | 四类：①食品、药品、医疗器械、化妆品、特种设备、重点工业产品领域处罚；②限制生产经营／责令停产停业／限制从业；③降低资质等级／吊销许可证件／吊销营业执照／责令关闭；④列入严重违法失信名单（第八条） |
| 系统落点 | `cases.level`、`rule_versions.level` |
| 现有问题 | 平台用**四级**：minor / general / serious / severe。「严重违法失信名单」是名单，不是处罚等级，被错误地做成了第四级。应改为三级，名单单列为 `case_type='blacklist'` |

**判定要点**：等级不是企业自选的，是由处罚决定书内容决定的。平台让用户在下拉框里选「一般／严重」是错的——应改为录入处罚类型、裁量阶次、罚没款金额、是否属于重点领域，由系统按第七条、第八条自动定级。

#### ⚠️ 最容易判错的一处：罚款金额相同，等级可能相反

107 号令第七条第一项第三目规定，「较低数额罚款」必须是**按照从轻或者减轻处罚的裁量阶次**，对经营主体处以 5 万元以下罚款。也就是说：

| 情形 | 裁量阶次 | 罚款金额 | 等级 | 公示期 |
|---|---|---|---|---|
| A | 从轻或减轻 | 3 万元 | **轻微** | 3 个月自动停止，无需申请 |
| B | 一般或从重 | 3 万元 | **严重**（重点领域）／一般（非重点领域） | 重点领域 3 年，满 1 年可申请 |
| C | 任意 | 8 万元 | 严重（重点领域）／一般（非重点领域） | 同上 |

盐城市市场监管局 2026-09-20 发布的服务指南把这一条单列成表格第 3、4 行，明确「非较低数额罚款：罚款数额虽在 5 万元以下，但裁量阶次不是从轻或减轻处罚」属**严重**类别。

**结论**：平台只收「罚款金额」字段是不够的，必须加「裁量阶次」（从轻／减轻／一般／从重）。缺这个字段，3 万元罚款可能被误判为轻微直接放过，也可能被误判为一般让企业白等。

另注：重点领域的判定不按企业所属行业，而是**按处罚决定书所依据的法律**认定（盐城指南原文）；重点工业产品范围以总局《全国重点工业产品质量安全监管目录》为准。

### 字段 5｜最短公示期

| 类型 | 最短公示期（可申请修复） | 最长公示期（自动停止公示） | 条号 |
|---|---|---|---|
| 轻微（警告） | —— 不予公示，不存在修复 | —— | 第七条 |
| 轻微（通报批评／低额罚款） | 无需申请 | 公示满 3 个月自动停止 | 第七条 |
| 一般 | **3 个月** | 1 年 | 第九条 |
| 严重①重点领域处罚 | 1 年 | 3 年 | 第八条 |
| 严重②限制生产经营／责令停产停业／限制从业 | 1 年（且处罚限制期限届满） | 3 年（且限制期限届满） | 第八条 |
| 严重③降级／吊销证照／责令关闭 | **不得申请提前修复** | 3 年到期自动停止 | 第八条 |
| 严重④列入严重违法失信名单 | 1 年 | 3 年 | 第十三条 |

| 项 | 内容 |
|---|---|
| 系统落点 | `rule_versions.definition.months` |
| 现有问题 | seed 里 general 配的是 6 个月（旧办法），现行是 3 个月。**这是最直接的错误**——企业会多等 3 个月 |

**必须补的能力**：现在只有一个 `months` 字段，无法表达「可申请时点」与「自动停止时点」两个不同日期，也无法表达「吊销类不可申请」。建议 `definition` 增加：

```json
{
  "applyable": true,          // 是否可申请提前修复；吊销证照类为 false
  "applyMonths": 3,           // 最短公示期（可申请）
  "autoStopMonths": 12,       // 最长公示期（自动停止）
  "limitMustExpire": false    // 是否要求处罚限制期限同时届满（严重②为 true）
}
```

### 字段 6｜可申请时点起算

| 项 | 内容 |
|---|---|
| 法规口径 | 「行政处罚信息的公示期限起点以行政处罚作出时间为准」（58 号令第十五条）。107 号令未另设起算规则，沿用同一口径 |
| 经营异常名录 | **无起算、无等待期**。已改正即可申请（第十二条） |
| 系统落点 | `cases.listed_date` |
| 现有问题 | `listed_date` 语义模糊——是「处罚决定作出日」还是「公示上线日」？两者可能差几天到几周。必须明确为**处罚决定作出日**，并在录入界面写明。另：经营异常名录类不应有起算日 |

### 字段 7｜前置条件① 已履行义务

| 项 | 内容 |
|---|---|
| 法规原文 | 「已经自觉履行行政处罚决定中规定的义务」（107 号令第十一条第一项） |
| 证明方式 | 58 号令第十九条：行政处罚机关出具的「责任义务已履行完毕」意见，或其他可说明履行完毕的材料（缴款凭证等） |
| 系统落点 | `cases.obligation_at` |
| 现有问题 | 逻辑正确。但提示文案「缺少缴款凭证或履行证明」过于单一——法规允许「其他可说明履行完毕的材料」，不限于缴款凭证 |

### 字段 8｜前置条件② 已纠正

| 项 | 内容 |
|---|---|
| 法规原文 | 「已经主动采取相关整改措施，消除危害后果和不良影响」（107 号令第十一条第二项） |
| 注意 | 旧办法表述是「主动消除危害后果和不良影响」，107 号令改为「主动采取相关整改措施，消除……」——**重心从结果转向行为**，只要采取了措施即可，不要求结果完全消除 |
| 系统落点 | `cases.rectified`、`cases.rectify_at` |
| 现有问题 | 字段名和判定逻辑可沿用，但界面文案应改为「已主动采取整改措施并消除危害后果和不良影响」，不要写成「整改完成」 |

---

### 字段 9｜前置条件③ 无新增同类

| 项 | 内容 |
|---|---|
| 法规原文 | 「未因同一类违法行为再次受到市场监督管理部门行政处罚」（107 号令第十一条第三项） |
| 范围 | ①**同一类违法行为**，不是任何违法行为；②再次受**市场监管部门**处罚，不含税务、海关等其他部门；③时间范围是**自原处罚作出之日起至申请日**，法规未设固定窗口 |
| 系统落点 | `cases.no_new_similar`、`rule_params.similar_window_months` |
| 现有问题 | `similar_window_months=12` 是**平台自造**的口径，法规里没有「近 12 个月」。这会导致：企业 12 个月前有同类处罚 → 平台判「可以申请」，但法规判「不可以」。**属于放行风险，比误驳更危险** |

**修改建议**：去掉时间窗口参数，改为判断「自处罚决定作出日至申请日之间，是否存在同一类违法行为的市场监管处罚」。字段 `no_new_similar` 保留三态即可。

### 字段 10｜所需材料

| 项 | 内容 |
|---|---|
| 法规原文 | 107 号令第十四条，四项：①信用修复申请书；②**申请人主体资格文件**；③守信承诺书；④履行法定义务、纠正违法行为、实施整改等相关材料 |
| 补充 | 同条第二款：能通过政务信息共享平台获取的，**不得要求申请人重复提供**（平台应在清单上标注「可共享免交」） |
| 经营异常名录 | 桂林市局指引：申请书、守信承诺书、（履行义务材料为**非必填**） |
| 系统落点 | `rule_versions.definition.materials` |
| 现有问题 | 现有 5 项：apply / promise / rectify / auth / list。**缺「申请人主体资格文件」（营业执照复印件等）**——这是必备项，缺了会被退回；多了 auth（授权委托书）、list（材料目录），这两项法规未要求，应标为「视情况」而非必备 |

**建议材料键**：

| key | 名称 | 必备性 |
|---|---|---|
| `apply` | 信用修复申请书 | 必备 |
| `subject` | 申请人主体资格文件 | 必备（**需新增**） |
| `promise` | 守信承诺书 | 必备 |
| `rectify` | 履行义务、纠正违法、整改材料 | 必备 |
| `auth` | 授权委托书 | 视情况（委托办理时） |
| `list` | 材料目录 | 视情况 |

### 字段 13｜常见驳回原因

| 项 | 内容 |
|---|---|
| 法规依据（硬性驳回） | ①申请时未满最短公示期；②未履行处罚决定义务；③未采取整改措施；④因同一类违法行为再次被市场监管处罚；⑤可能危害国家安全、社会公共利益（107 号令第十八条）；⑥隐瞒真实情况、弄虚作假（第二十三条）；⑦被列入信用信息异常企业名录（海关，282 号令） |
| 实务常见（需法学院确认） | 材料不全（缺主体资格文件）、主体不符（申请人与被处罚主体不一致）、机关选错（未向作出决定的机关申请）、司法程序未终结（复议／诉讼期间不暂停公示，58 号令第十六条） |
| 系统落点 | `rule_versions.definition.rejectReasons`（已实现，最多 10 条） |
| 现有问题 | 字段已加，但内容为空。建议先把上面 7 条法定驳回理由录入，实务类等法学院确认 |

**特别提示**：第 ⑥ 项后果很重——弄虚作假一经发现，撤销修复决定、公示期**重新计算**、且 3 年内不得再申请（第二十三条）。这条必须在前端显著提示。

## 四、六类失信情形的真实规则速查

### 4.1 市场监管领域行政处罚信息

- **依据**：107 号令第七至十一条、第十四至十七条
- **路径**：最短公示期满 → 向作出处罚的部门申请 → 7 个工作日决定
- **注意**：吊销许可证件／营业执照／责令关闭类，**只能等 3 年自动停止，不能申请提前修复**

### 4.2 经营异常名录

- **依据**：107 号令第十二条、第十六条
- **无等待期、无公示期**。五种情形满足其一即可申请（未报年报已补报／未公示信息已履行／未变更名称已完成变更／住所失联已变更或可重新联系／其他违法行为已改正）
- **时限**：受理后 2 个工作日
- **这是平台最适合做「L1 完整支持」的类型**——条件单一、有明确证明、无日期计算，出错概率最低

### 4.3 市场监管严重违法失信名单

- **依据**：44 号令第十六条、第二十一条；107 号令第十三条
- 列入满 **1 年**可申请移出；满 **3 年**自动移出
- 条件：已履行义务 + 已消除危害后果 + 未再受较重行政处罚
- 依法实施的限制措施期限未届满，不得提前移出
- **平台现状**：做成了 L2 不判定。但这类条件明确、可判定，**建议升级为 L1**

### 4.4 重大税收违法失信主体

- **依据**：国家税务总局令第 54 号，2022-02-01 施行
- 四条路径：
  1. 缴清税款、滞纳金、罚款 + 公布满 **6 个月** + 期间无新增税收违法 + 非 5 年内两次以上
  2. 破产重整／和解 + 法院裁定 + 税务机关依法受偿
  3. 突发事件突出贡献 + 省级政府证明
  4. 公布满 **3 年**自动撤出（无需申请）
- **不予提前停止**：被确定后又发生偷税、逃避追缴、骗退税、抗税、虚开发票等；5 年内两次以上
- 时限：受理 2 日、决定 15 日、停止公布 5 日
- **注意**：税务的 6 个月与市场监管的 3 个月不同，不能套用同一参数

### 4.5 海关失信企业

- **依据**：海关总署令第 282 号，**2026-04-01 施行**（251 号令已废止）
- 分类：轻微（警告、通报批评、简易程序处罚，不公示）／一般（公示 1 年）／严重（公示 3 年）
- 条件：一般失信公示满 **3 个月**、严重失信公示满 **1 年**，且作出信用承诺
- 材料：纠正违法行为、消除不良影响的证明材料；信用承诺书；海关总署规定的其他材料
- 时限：受理 3 个工作日、决定 7 个工作日（复杂可延 10 个工作日）
- **不予受理**：被列入信用信息异常企业名录的

### 4.6 法院失信被执行人

- **依据**：法释〔2017〕7 号
- 纳入期限 **2 年**，情节严重可延长 1–3 年
- 提前删除：积极履行义务或主动纠正失信行为，法院**可以**（裁量）决定提前删除
- 删除情形：全部履行完毕／达成执行和解并履行完毕／法院裁定终结执行
- 救济：认为纳入错误的，向执行法院申请纠正（第十一条）
- **关键判断**：这不是「申请—审核—决定」的行政程序，没有申请材料清单、没有办理时限、没有受理机关。**平台做 L3 仅导航是正确的**，坚持不改

## 六、五个问题已全部查明，不必再转法学院

上一版列了五个"必须让法学院确认"的问题。联网核验后发现，四个有直接可查的官方口径，第五个能从条文推出。逐条给答案。

| # | 问题 | 查明结论 | 依据强度 |
|---|---|---|---|
| 1 | 新老办法怎么衔接 | **从旧兼从轻**，两者取其轻 | 权威解读，非法条 |
| 2 | 「同一类违法行为」怎么认 | **违反同一部法律法规** | 省局官方答复 |
| 3 | 吊销证照能否提前修复 | **不能**，只能等 3 年自动停止 | 市局服务指南明确 |
| 4 | 文书能不能自创格式 | **不能**，须用总局统一范本 | 107 号令第二十九条 |
| 5 | 平台凭证有无法律效力 | **无**，只有行政机关的决定书有效 | 107 号令第十九条 + 国办 22 号文 |

### 问题 1｜新老办法衔接：从旧兼从轻

107 号令 2025-12-25 施行。对施行前已公示但尚未修复的存量信息，按「两者取其轻」处理：

- 新规更轻的，适用新规 → 如价格、广告类一般处罚，公示期由 6 个月缩短为 3 个月
- 新规更重的，沿用旧规 → 如重点领域非从轻阶次的小额罚款，旧规 3 个月，新规 1 年，仍按 3 个月

这与《行政处罚法》第三十七条「从旧兼从轻」的原理一致。

**落地方式**：`rule_versions` 同时保留新旧两个版本，`effective_from` 分别设为旧办法施行日和 2025-12-25，判定时按「对当事人更有利的时点」取值。不要简单地按申请日套新版。

### 问题 2｜「同一类违法行为」= 违反同一部法律法规

广东省市场监管局对同一问题的公开答复原文：

> 《市场监督管理信用修复管理办法》第十一条第（三）项所列"未因同一类违法行为再次受到市场监督管理部门行政处罚"指的是**违反同一部法律法规**的违法行为。

**落地方式**：比对维度是「处罚决定书援引的法律法规名称」，不是违法行为的性质描述，也不是处罚事项分类。`cases` 需要新增字段记录援引法条（至少记法规名称）。

配合另一条口径：若在前一条处罚的最短公示期届满前又因同类违法行为被罚，**前一条的最短公示期要随新处罚重新起算**，须等最后一次处罚的最短公示期届满、且期间无新增同类，才能一并申请修复多条。平台现在的实现完全没有这个逻辑——它只看「有没有新增」，不看「重新起算」。

### 问题 3｜吊销证照类：确认不可申请

盐城市市场监管局 2026-09-20 发布的服务指南用表格逐类列明，第 7 类原文：

> 降低资质等级；吊销许可证件；吊销营业执照；责令关闭 → 严重类别，公示期 3 年，期满自动停止公示，**不得申请信用修复**。

同一张表还解决了另外两个易错点：

- 含没收违法所得、没收非法财物的处罚 → **一般类别**（非重点领域）公示 1 年，满 3 个月可申请；重点领域属严重类别
- 限制开展生产经营活动、责令停产停业、限制从业 → 严重类别，**公示期 3 年且行政处罚限制期限届满**才自动停止；满 1 年且限制期限届满才可申请

**落地方式**：`definition` 必须能表达三种路径——「可申请提前修复」「只能等到期」「需同时满足限制期限届满」。现在只有一个 `months`，无法区分。

### 问题 4｜文书必须用总局统一范本

107 号令第二十九条：

> 国家市场监督管理总局根据本办法制定全国统一的信用修复信息化系统技术方案以及**相关文书格式范本**。

总局信用修复指南页面已提供可下载的样式文件：`信用修复申请书(样式).docx`、`守信承诺书(样式).docx`、`送达地址确认书(样式).docx`。

**结论**：平台不能自创文书格式。正确做法是：

1. 提供官方范本的下载入口
2. 平台的文书工坊只做「内容辅助填写」，产出的文件明确标注「草稿，须按官方样式誊录」
3. 不要在生成的文书上放平台抬头、编号、印章样式

这条会改变产品形态——从「生成文书」变成「辅助填写 + 官方范本下载」。不做这个调整，法律风险是实打实的。

### 问题 5｜只有行政机关的「信用修复决定书」有法律效力

107 号令第十九条：

> 经当事人同意，市场监督管理部门可以通过市场监管信用修复全国统一平台、电子邮件等方式送达信用修复决定书。……通过电子方式送达的信用修复决定书，当事人提出需要纸质的，市场监督管理部门应当提供。**电子文书与纸质文书具有同等法律效力。**

国办发〔2025〕22 号第七项：

> 「信用中国」网站统一汇总、每日更新、及时共享各类信用修复结果，并为信用主体提供**信用修复决定书下载服务**。

**结论**：全流程中唯一具有法律效力的是行政机关出具的信用修复决定书，电子版与纸质版同等效力，由市场监管信用修复全国统一平台和「信用中国」提供下载。平台自制的二维码凭证不具备任何法律效力。

**必须改的地方**：平台当前的「数字凭证」如果对外称「信用修复证明」，有被认定为出具虚假证明的风险。建议改为：

| 现在的表述 | 建议表述 |
|---|---|
| 信用修复凭证 | 办理进度记录 |
| 修复证明 | 材料自述与提交记录 |
| 凭证核验通过 | 材料清单核对完成 |
| —— | 增加一个按钮：「到信用中国下载官方决定书」 |

后者不仅安全，而且更有用——企业真正需要拿走的是官方决定书。

### 附带查明的两条产品红线

**红线一：不能出现「征信修复」「洗白」「消除记录」字样**

吉安市人民银行、市场监管局、行政审批局联合公告明确：

> 「信用修复」是指公共信用信息领域的修复机制，针对的是「信用中国」等公共信用信息平台公示的行政处罚信息、严重失信主体名单等，与人民银行的征信系统无关。而「征信修复」在现行法规和政策中并无此概念，社会上以「征信修复」「征信洗白」「征信铲单」等为噱头的宣传或广告均涉嫌虚假宣传。

平台定位是公共信用信息修复，与金融征信无关。对外文案、SEO、宣传物料里一旦出现这几个词，属于虚假宣传风险。

**红线二：不得代客户伪造任何材料**

多地专项治理公告把「伪造、变造、买卖国家机关公文、证件、印章，或者提供虚假证明材料，协助信息主体申请信用修复」列为重点打击对象。平台若提供「整改说明自动生成」且内容不实，风险会传导到平台自己。文书工坊里的占位符必须保持「【待补充】」形态，不能被一键填充成看似真实的事实陈述——现有实现（`db/catalog.js` 里全用「【待补充：…】」）这一点是对的，要保持。

### 真正还需要法学院做的两件事

查完之后，法律层面的问题基本清零，剩下的是地方落地：

1. **湘潭本地的执行口径**：湘潭市市场监管局是否另有实施细则或窗口要求？「两书同达」在湖南落地到什么程度？这些只有本地能问到
2. **审校平台生成文本的表述**：文书草稿、诊断结论、风险提示的措辞，需要有人从「不构成法律意见」的角度过一遍

这两件不需要法学院做研究，只需要他们以本地从业者身份确认。

## 七、合规知识库内容条目（19 条，可直接入库）

字段对应 `knowledge_entries`：`category` / `title` / `body` / `source_url` / `issuer` / `effective_at`。
分类取值与前端一致：`policy`（法规政策）、`guide`（办理指引）、`case`（典型案例）。
**入库后须将 `review_status` 置为 `reviewed` 并填写 `review_note`**，否则前端不展示。

### policy 类（法规政策，9 条）

**1. 失信信息统一分为轻微、一般、严重三类**
> 依据国办发〔2025〕22 号第二项，失信信息分为三类：轻微失信信息可不予公示或法定责任义务履行完毕即可申请修复，确需公示的公示期最长 3 个月；一般失信信息公示期最短 3 个月、最长 1 年；严重失信信息公示期最短 1 年、最长 3 年。各领域具体分类标准由行业主管部门制定并在「信用中国」网站统一发布。
> 来源：国务院办公厅 · https://www.gov.cn/zhengce/content/202506/content_7029483.htm · 2025-06-22

**2. 市场监管行政处罚信息的修复条件**
> 依据市场监管总局令第 107 号第十一条，最短公示期届满后申请信用修复，应同时符合：①已经自觉履行行政处罚决定中规定的义务；②已经主动采取相关整改措施，消除危害后果和不良影响；③未因同一类违法行为再次受到市场监督管理部门行政处罚。
> 来源：市场监管总局 · https://www.gov.cn/govweb/zhengce/202512/content_7050596.htm · 2025-12-25

**3. 仅受警告的处罚信息不予公示**
> 依据 107 号令第七条，仅受到警告的行政处罚信息不予公示；仅受通报批评、仅受较低数额罚款（经营主体 5 万元以下、相关责任人员 5000 元以下）的，公示期满 3 个月由市场监管部门停止公示。此类信息不存在「申请修复」环节。
> 来源：市场监管总局 · 同上 · 2025-12-25

**4. 吊销证照类不适用提前修复**
> 依据 107 号令第八条，降低资质等级、吊销许可证件、吊销营业执照、责令关闭的行政处罚信息，公示期届满 3 年的，由市场监管部门停止公示。该类情形未规定可申请提前停止公示。
> 来源：市场监管总局 · 同上 · 2025-12-25

**5. 经营异常名录移出的五种情形**
> 依据 107 号令第十二条，被列入经营异常名录的当事人，符合下列条件之一即可向登记地市场监管部门申请移出：①未按期报送公示年报的，已补报并公示未报年份年报；②未按责令期限公示企业信息的，已履行公示义务；③未依法办理名称变更登记的，已完成变更登记；④通过登记住所无法取得联系的，已完成住所变更登记或可重新取得联系；⑤因其他违法行为被列入的，已改正该违法行为。移出同时停止公示列入信息。
> 来源：市场监管总局 · 同上 · 2025-12-25

**6. 严重违法失信名单的移出条件**
> 依据 107 号令第十三条，被列入市场监督管理严重违法失信名单的当事人，公示期满 1 年后可申请移出，条件为：①已自觉履行行政处罚、行政裁决等行政决定中规定的义务；②已主动采取整改措施，消除危害后果和不良影响；③未再受到市场监管部门较重行政处罚。公示期满 3 年的，由市场监管部门移出。依法律、行政法规实施的管理措施期限尚未届满的，不得提前移出。
> 来源：市场监管总局 · 同上 · 2025-12-25

**7. 重大税收违法失信主体的修复条件**
> 依据国家税务总局令第 54 号第十八条，符合下列条件之一可申请提前停止公布：①按税务处理决定书、处罚决定书缴清（退）税款、滞纳金、罚款，且失信信息公布满 6 个月；②破产，法院出具批准重整计划或认可和解协议裁定书，税务机关依法受偿；③突发事件期间因抢险救灾、疫情防控、重大项目建设或履行社会责任作出突出贡献。公布满 3 年的自动撤出，无需申请。
> 来源：国家税务总局 · 2022-02-01

**8. 海关失信信息的修复条件**
> 依据海关总署令第 282 号第三十六条，企业纠正违法行为、消除不良影响，且符合下列条件的可申请修复：①一般失信信息公示满 3 个月，或严重失信信息公示满 1 年；②作出信用承诺；③法律、行政法规、海关总署规定的其他条件。海关自收到申请 3 个工作日内决定是否受理，受理之日起 7 个工作日内作出修复决定，情况复杂可延长 10 个工作日。
> 来源：海关总署 · https://www.gov.cn/gongbao/2026/issue_12746/202605/content_7069427.html · 2026-04-01

**9. 法院失信被执行人不适用行政信用修复**
> 依据法释〔2017〕7 号，纳入失信被执行人名单的期限为 2 年，情节严重可延长 1 至 3 年。被执行人积极履行义务或主动纠正失信行为的，人民法院可以决定提前删除失信信息。删除路径为：全部履行完毕、达成执行和解并履行完毕、人民法院裁定终结执行。该程序由执行法院依职权处理，不属于行政机关信用修复的受理范围。
> 来源：最高人民法院 · https://www.court.gov.cn/fabu/xiangqing/37172.html · 2017-05-01

### guide 类（办理指引，6 条）

**10. 市场监管信用修复的四类申请材料**
> 依据 107 号令第十四条，申请信用修复应提交：①信用修复申请书；②申请人主体资格文件；③守信承诺书；④履行法定义务、纠正违法行为、实施整改等相关材料。能通过政务信息共享平台获取的材料，市场监管部门不得要求重复提供。
> 来源：市场监管总局 · 2025-12-25

**11. 市场监管信用修复的办理时限**
> 依据 107 号令第十四至十七条：材料齐全的，自收到申请 2 个工作日内受理；申请移出经营异常名录的，自受理 2 个工作日内作出决定；申请停止公示行政处罚信息或移出严重违法失信名单的，自受理 7 个工作日内作出决定，情况复杂经批准可延长 10 个工作日；准予修复的，自决定作出 3 个工作日内完成数据处理。
> 来源：市场监管总局 · 2025-12-25

**12. 经营异常名录的线上办理路径**
> 通过国家企业信用信息公示系统（https://www.gsxt.gov.cn）首页「信用修复」入口，使用电子营业执照扫码登录后在线提交。也可到登记地市场监管部门现场申请。移出经营异常名录不收取任何费用。申请材料模板可在公示系统下载。
> 来源：国家企业信用信息公示系统 / 桂林市市场监管局指引

**13. 信用修复不收取任何费用**
> 市场监管部门办理年报公示、移出经营异常名录、信用修复，均不收取任何费用，也未授权或委托任何第三方收费代办。凡以「加快修复」「内部渠道」「包过」为名收取费用或索要财物的，均非官方行为。企业信用修复是政府提供的公共服务，须先纠正失信行为、履行义务、达到最短公示期，才能通过官方渠道申请。不存在付费删除记录的合法途径。
> 来源：市场监管总局信用监管司公开表态；各地市场监管局风险提示 · 2026

**14. 弄虚作假的后果**
> 依据 107 号令第二十三条，当事人在信用修复过程中故意隐瞒真实情况、弄虚作假的，不得准予修复；已准予的应撤销，恢复至修复前状态，公示期自撤销之日起重新计算且不得提前停止公示。同时该不予修复或撤销决定在公示系统公示 3 年，自决定作出之日起 3 年内不得申请信用修复。
> 来源：市场监管总局 · 2025-12-25

**15. 「两书同达」与修复告知**
> 依据国办发〔2025〕22 号第四项，鼓励推广「两书同达」：向信用主体送达行政处罚决定书或列入严重失信主体名单决定书时，同步送达信用修复告知书，确保企业第一时间知晓修复政策。企业收到处罚决定书时，可一并确认修复的起算时间与最短公示期。
> 来源：国务院办公厅 · 2025-06-22

### case 类（典型案例，1 条）

**16. 有偿删除失信信息的法律风险**
> 依法应当公示的失信信息，在法院、行政机关解除相关措施前，任何第三方无权删除。常见违法手段包括：伪造法院结案或撤销文书用于申诉（涉嫌伪造国家机关公文）、冒用企业名义伪造公章发起虚假投诉、买通平台人员删改数据、技术手段侵入官方系统篡改后台。整条产业链涉嫌非法经营、破坏计算机信息系统等犯罪，委托方与操作方均需担责。已有多起企业付费后对方失联的报案记录。
> 来源：央广网《150 元消除一条失信信息？信用修复黑灰产盯上企业端》· https://www.cnr.cn/mspd/msyx/20260714/t20260714_527708969.shtml · 2026-07-14

### policy 类（补充 3 条，核验过程中新查明）

**17. 罚款金额相同，失信等级可能相反（关键判定规则）**
> 依据 107 号令第七条，「较低数额罚款」须同时满足两个条件：①按从轻或者减轻处罚的裁量阶次；②经营主体 5 万元以下、相关责任人员 5000 元以下。缺任一条件即不属于轻微。同一笔 3 万元罚款，按从轻或减轻阶次作出的属轻微信息，公示满 3 个月自动停止；非从轻减轻阶次作出的，重点领域属严重信息（最短公示期 1 年），非重点领域属一般信息（最短公示期 3 个月）。重点领域按处罚决定书所依据的法律认定，重点工业产品范围以《全国重点工业产品质量安全监管目录》为准。
> 来源：市场监管总局令第107号 / 盐城市市场监管局服务指南 · https://scjgj.yancheng.gov.cn/art/2026/9/20/art_21470_4455305.html · 2026-09-20

**18. 「信用修复」与「征信修复」是两回事**
> 信用修复指公共信用信息领域的修复机制，针对「信用中国」等平台公示的行政处罚信息、严重失信主体名单，由各级社会信用体系建设牵头部门协调监督。而「征信修复」在现行法规和政策中并无此概念，以「征信修复」「征信洗白」「征信铲单」为噱头的宣传或广告均涉嫌虚假宣传。金融信用信息基础数据库中的信息，除确有错误、遗漏外，任何机构或个人无权擅自修改或删除。
> 来源：中国人民银行吉安市分行、吉安市市场监督管理局、吉安市行政审批局联合公告 · https://www.jian.gov.cn/news-show-108206.html

**19. 新规施行前的存量信息，从旧兼从轻**
> 对 107 号令施行前已公示但尚未修复的存量信息，按「两者取其轻」判定：新规公示期缩短、条件放宽的适用新规，新规延长公示期、收紧条件的沿用原规定，不溯及既往增加经营主体负担。例如价格、广告等非重点领域一般处罚，原最短公示期 6 个月，新规为 3 个月，可适用新规；食品领域 5 万元以下但非从轻减轻阶次的处罚，原公示 3 个月，新规为 1 年，应沿用原规定。
> 来源：《信用修复提质增效的制度升级与实践》（中国工商出版社）· 2026-08-18

## 八、平台自身的合规义务（不对外展示，内部执行）

这部分不是给企业看的，是平台自己必须满足的。结合《个人信息保护法》与《网络数据安全管理条例》。

| # | 义务 | 依据 | 平台现状 |
|---|---|---|---|
| 1 | 处理敏感个人信息须取得**单独同意** | 个保法第二十九条 | 未见单独同意流程，需补 |
| 2 | 处理敏感个人信息须**告知必要性与对个人权益的影响** | 个保法第三十条 | 隐私政策未覆盖 |
| 3 | 处理前须制定并**集中公开展示**个人信息处理规则 | 网络数据安全管理条例 | 需补 |
| 4 | 收集个人信息须为提供服务所必需，**不得超范围收集** | 个保法第六条、条例 | 上传页无字段级说明 |
| 5 | 个人请求查阅、复制、更正、删除须提供**便捷途径**，不得设不合理条件 | 个保法第四十四至四十七条 | 未见注销/删除入口 |
| 6 | 须定期开展**个人信息保护合规审计** | 条例 | 无 |
| 7 | 委托处理须约定目的、方式、范围与安全义务，**至少保存 3 年处理记录** | 条例 | 无记录机制 |
| 8 | 建立健全**网络数据安全事件应急预案** | 条例 | 无 |

**当前最紧迫的三件**（都能在一周内落地）：

1. 上传页加显著提示：请勿上传身份证、银行卡照片；确需上传的，说明必要性并单独勾选同意
2. 隐私政策补「敏感个人信息处理」专章，说明必要性、影响、保存期限
3. 建立保留期：事项办结后 6 个月自动清理附件原文，挂到已有 `scheduled_jobs`
