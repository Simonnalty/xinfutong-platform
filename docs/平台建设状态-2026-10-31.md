# 信复通平台建设状态 · 2026-10-31

项目目录：`/home/simon/项目/信复通/app`。本轮仅建设平台，不包含专利、赛事文案和申报工作。分支为 `codex/platform-build`，尚未提交或推送 Git。

## 已实现的内部功能

| 模块 | 实际能力 |
| --- | --- |
| 企业与事项 | 注册后自行建档、建案、修改事实；负责人关系、服务端归属校验、默认任务 |
| 附件证据 | 私有上传下载、文件格式及大小校验、来源日期、摘要、人工核录、归档；修复结果要求有效官方材料 |
| 诊断 | 复核规则版本、机关及类型匹配、有效日期、满足／不满足／未知、事实与规则历史快照 |
| 文书 | 中性模板、事实锁定、一致性校验、编辑与历史恢复、待填项拦截、PDF／Word；可选 AI 润色 |
| 办理 | 任务负责人／期限／依赖／附件；提交、受理、退回、修复的前置条件及时间线 |
| 同步核验 | 人工核录具体事项快照、模拟来源区分、授权适配器入口；持久定时任务、租约、重试和暂停 |
| 异议 | 基于官方材料及真实差异生成草稿；补充说明版本、PDF、提交回执、回复、催办日期、重新核验关闭 |
| 状态凭证 | 不可变快照、签名摘要、前序摘要、重复保护、到期与撤销；官方依据归档后凭证失效 |
| 机构协作 | 企业授权机构及成员、读写分离、撤销即时生效、机构列表、风险汇总、批量复查的逐项结果 |
| 知识与提醒 | 来源／复核／发布、分类检索、个人已读、政策／复查／逾期配置、异议催办站内通知 |
| 融资／投标应用 | 选择用途和接收方、限期分享／撤销、扫码核验、PDF 说明及私有附件目录 |

公开核验页不展示联系人和原始附件。平台核录代表人工记录已提供材料，不代表向行政机关联网验证。材料生成、异议草稿、状态凭证、用途分享分别展示自身状态。

- 16 项 `node:test` 集成测试全部通过，使用随机独立数据库及账号，结束后清理；未用旧测试改写业务库。
- 覆盖：新用户建档重登与越权、证据及修复前置条件、文书事实冲突／历史／PDF／Word、真实差异异议、凭证篡改／撤销／失效、定时任务租约／重试／暂停、规则边界及历史、任务依赖、提交回执、机构撤权／批量权限、启动不恢复已撤销授权、知识复核／个人提醒、分享到期／撤销／附件权限、异议补充／催办、未支持事项及中性模板。
- Vue/Vite 生产构建通过；主包约 1.21 MB，存在体积提示，后续应按路由和图表拆包。
- 浏览器隔离环境验收：企业登录、建立企业和处罚事项、查看材料编辑及版本入口、保存巡检计划、授予机构只读、机构登录查看授权事项及禁用批量写操作。发现并修复机构列表事项名称字段错误；浏览器未报告运行错误。
- 中文材料 PDF 已转换为图片检查。Word 验证为可解析 DOCX 及预期 XML 内容，未做 Office／LibreOffice 排版验收。用途 PDF 的内容和文件格式通过接口测试，二维码未做实体手机扫码验收。
- 业务库切换前另存受限权限 SQL 备份，包含当时 27 张表及数据；未进行恢复演练。

## 后续仍需完成或配置

1. 根据可靠现行来源复核规则和知识条目，再发布适用版本；当前没有经过核验的默认真实法律规则。事实判定仍依赖用户填报和人工核录，尚未做每个事实到附件页码的精细映射。
2. 真实第三方渠道需要取得授权并实现适配器；当前没有真实自动采集连接，人工核录与模拟不能视为实时监测。异议尚无真实自动投递渠道。
3. 补充银行／招标方的具体材料要求配置及合作入口；目前仅提供材料准备和核验，没有银行授信或招标系统接口。
4. 知识条目适用范围匹配、提醒处理／关闭状态及通知渠道可进一步细化；当前是发布筛选、个人已读及配置站内提醒。
5. 全路径浏览器端到端验收、手机适配与实际扫码、Word 排版、备份恢复演练、生产并发及安全配置检查。
6. 在可从手机访问的 HTTPS 地址部署，固定签名密钥并配置公开基址，再验证对外分享。当前为本地运行；未部署到公网，也未推送私人仓库。
