# 信复通平台建设计划清单

**目标：** 在现有平台上补齐企业自行办理辅助、修复后同步核验及机构管理，形成可以完整操作和验证的 SaaS 平台。

**架构：** 继续 Vue 3 + Node.js + MySQL，沿用现有路由、服务和迁移机制；新增服务按证据、提醒、机构协作等业务职责拆分。企业、事项、事实与证据是公共基础，材料和流程在其上运行，监测、异议和核验共用来源快照。

**范围：** 只包含平台功能、界面、数据、测试和运行交付。本文按用户要求提供任务清单和验收标准，不包含比赛申报材料、路演、商业计划或专利工作。

**需求来源：** `/home/simon/项目/信复通/app/docs/需求文档.md` 及用户本轮对平台用途和功能的补充。旧文档中的完成标记和演示规则须结合当前代码重新核对。

**执行方式：** 按依赖逐项推进；具体实施时使用 executing-plans 工作流。本轮已完成内部业务流程的实现与隔离测试；实际状态和接入边界见 `docs/平台建设状态-2026-10-31.md`。未勾选项包含仍需增强或未完成全面验收的部分。每完成一项记录实际改动和验收结果，更新共享记录。
