# 前端美化方向预览

打开 `six-directions.html` 查看六格候选，或直接打开以下离线 HTML。三个主方向均支持手机左上角抽屉、工作台与知识库切换、法规搜索、事项详情弹窗。预览不连接生产接口。

| 选项 | 文件 | 重点 | 取舍 |
|---|---|---|---|
| A 澄明 | `candidate-1.html` | 浅色固定侧栏，事项卡片与紧凑动态栏 | 最接近现有操作习惯，适合先完成三端统一 |
| B 青岚 | `candidate-3.html` | 顶部导航与办理路径 | 适合讲解流程，工作台首屏更长 |
| C 墨序 | `candidate-5.html` | 档案目录与法规阅读布局 | 更有文科与法规气质，操作入口较克制 |

另外三个候选：同舟（深色侧栏）、矩阵（紧凑数据台）、经纬（法规索引）。没有替用户决定最终方向。

版式来自业务内容：事项主次决定 A 的卡片层级；办理节点决定 B 的路径结构；材料与法规的查阅需求决定 C 的档案结构。所有预览使用相同业务事实，比较的是展示方式。

## 验证

JS Playwright + Chromium 实测三个主方向，桌面 1440px、手机 375px，共六组：没有页面水平溢出，没有 JavaScript 页面错误；移动导航开关、知识库返回工作台、湖南法规筛选、事项弹窗均通过。截图为 `direction-{1,3,5}-{desktop,mobile}.png`。

skill 自带的 Python design_lint 因缺少 Python 版 Playwright 跳过，不能计作通过；以上结果来自独立 JS 浏览器实测和截图人工查看。参考截图与品牌约束见 `brand-spec.md`，业务核验边界见 `product-facts.md`。

用户已回复“选C”，确认文件为 `direction-approved.md`。正式前端在原有 Vue + Element Plus 中实现 C「墨序」，保留现有业务接口与权限；本地验证完成后另行按用户要求部署。
